שאלות נפוצות

מה ההבדל בין העלאת קובץ להתחברות דרך API?

העלאת קובץ מתאימה כשכבר הורדתם ייצוא מהר הביטוח. ההתחברות דרך API מושכת את הפוליסות ישירות, אחרי זיהוי בתעודת זהות וקוד חד-פעמי.

מה קורה לנתונים שלי?

בגרסה הנוכחית הנתונים נשמרים בדפדפן בלבד לאורך הסשן, ופרטי כרטיס אשראי אינם נשמרים כלל.

האם ההצעות אמיתיות?

בגרסת ההדגמה ההצעות מדומות ונוצרות אוטומטית סביב הפרמיה הנוכחית. חיבור לתעריפים אמיתיים דורש שילוב עם חברות הביטוח.

אילו סוגי כיסוי אפשר להשוות?

חובה + צד ג׳, וחובה + מקיף. אפשר לעבור בין השניים בלחיצה ולקבל הצעות חדשות.
