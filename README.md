# Rivo

השוואת ביטוחי רכב (הדגמה): עמוד נחיתה, הרשמה וכניסה עם OTP, "הביטוחים שלי" (מקובץ אקסל או מ-API מדומה של הר הביטוח), השוואת הצעות מ-10 חברות ובקשת הצעה.

## הפעלה

```bash
npm install
cp .env.example .env        # ומלאו DATABASE_URL (מחרוזת החיבור מ-Neon) ו-SESSION_SECRET
npm run db:setup            # יוצר את הטבלאות ב-Neon ומוסיף משתמשי דמה (רק כש-DEMO_MODE=1)
npm start                   # http://localhost:8000
```

`.env` לא נכנס לגיט. את מחרוזת החיבור לוקחים מ-Neon: Dashboard, Connect (כתובת עם `-pooler`).

## מה נשמר ב-Neon

| טבלה | תוכן |
| --- | --- |
| `users` | שם משתמש, סיסמה מגובבת (scrypt), שם, טלפון, דוא״ל, ת״ז, ספק כניסה, נעילה אחרי כשלונות |
| `login_challenges` | קוד OTP: נשמר רק ה-HMAC שלו, עם מספר ניסיונות ותוקף של שתי דקות |
| `sessions` | סשן: נשמר רק ה-SHA-256 של הטוקן שבעוגייה, עם תוקף מוחלט של 30 דקות |

נתוני הפוליסות, טפסי ההצעה והזמנות נשארים בדפדפן ולא נשמרים ב-DB. פרטי כרטיס אשראי לא נשמרים בשום מקום.

## כניסה והרשמה

- **שם משתמש וסיסמה** מחייבים קוד חד-פעמי (OTP) לטלפון. 5 סיסמאות שגויות נועלות ל-30 שניות; 3 קודים שגויים מחליפים את הקוד.
- **הרשמה** בשם משתמש וסיסמה נפתחת אחרי אימות הטלפון ב-OTP. הרשמה עם Google (Gmail) היא **מדומה**: אין OAuth אמיתי.
- **סשן:** עוגיית `HttpOnly` בלי `Max-Age` (נמחקת בסגירת הדפדפן), ותוקף מוחלט של 30 דקות שנאכף בשרת.
- **עמודים מוגנים:** `home.html`, `index.html`, `compare.html` וקבצי הנתונים מוגשים רק עם סשן תקף.

## מצב הדגמה ותצורה

| משתנה | משמעות |
| --- | --- |
| `DEMO_MODE=1` | משתמשי דמה במסך הכניסה, וקוד ה-OTP חוזר בתגובה ומוצג כ-SMS מדומה (אין ספק SMS) |
| `ALLOW_MOCK_GOOGLE=1` | כניסה והרשמה מדומות עם Google |

בסביבה אמיתית מכבים את שניהם (`0`), מחברים ספק SMS ו-OAuth אמיתי של Google, ומריצים מאחורי HTTPS (`NODE_ENV=production`).

## בדיקות

```bash
npm test                    # מסד בזיכרון (pg-mem), ללא רשת
TEST_DB=neon npm test       # נגד Neon האמיתי
npm run dev:memory          # שרת עם מסד בזיכרון, בלי Neon
```

## מבנה

- `server/`: שרת Express (`index.js`), נתיבי כניסה (`auth.js`), חיבור ל-Neon (`db.js`), אבטחה (`security.js`)
- `db/schema.sql`: הסכמה
- `api/`: הדמיית שירותי חברות הביטוח (ראו `api/README.md`)
- `*.html`, `auth.js`, `brand.js`, `header.css`, `theme.css`: הממשק
